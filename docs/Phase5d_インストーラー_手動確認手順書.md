# Phase 5d インストーラー 手動確認手順書

`docs/utteran_Phase5d_指示書.md`のStep 5「実機での検証」のうち、対話操作（ダイアログの
クリック、SmartScreen警告の実際の表示、ネイティブWebViewの目視）を伴うためツールから
自動化できない項目をまとめる。自動化できた項目（サイレントインストール／アンインストール、
配置レイアウト、`project_root()`解決、推論コア非混入）は`AISTATE.md`のPhase 5d記録を参照。

実施前に必ず`docs/Phase5d事前準備.md`の申し送り事項（uv package cacheの温cache問題、
uv未導入からの自動導入が実機未検証である点、`verify`段の罫線文字化けが未解決である点）を
確認すること。

## 前提

- `.\build.ps1`でビルド済みの`dist\installer\utteran-setup-<version>.exe`を用意する。
- 可能であれば、本機のuv package cacheを持たない別マシンまたは仮想マシンで最低1回実施する
  （`docs/Phase5d事前準備.md`の申し送り事項1）。本機だけでの検証は温cacheの所要時間しか
  測れない。
- 既存の`.venvs`、モデルcache、ジョブ履歴、GUI設定を壊さないよう、既定のインストール先
  （`%LocalAppData%\Programs\utteran`）とは別のテスト用ディレクトリを都度指定するか、
  仮想マシン／別ユーザーアカウントを使う。

## 1. インストール（対話）

1. `utteran-setup-<version>.exe`をダブルクリックで実行する。
2. **確認**: 管理者権限の昇格プロンプトが出ないこと。
3. **確認**: 言語選択（日本語／English）が機能すること。
4. **確認**: ライセンスページの直後に、サードパーティライセンス（ffmpeg GPLv3、pyannote
   モデルの利用条件）に関する情報ページが表示されること。
5. **確認**: インストール先選択の直後に、初回起動時に追加ダウンロードが発生する旨の
   情報ページが表示されること。
6. インストール先を選び、完了まで進める。
7. **確認**: 完了画面の「utteranを起動する」チェックボックスからGUIが起動できること。

## 2. 初回起動とセットアップウィザード（対話・ネイティブWebView）

1. スタートメニューの「utteran」から起動する。
2. **確認**: ネイティブWebViewウィンドウが実際に描画されること（`Phase5c_GUI_セットアップ
   ウィザード_手動確認手順書.md`のGUI目視項目と重複するため、詳細な画面確認はそちらに委ねる）。
3. **確認**: 初回セットアップウィザードが自動的に開始すること。
4. ウィザードに従い、任意の1プロファイル（`cpu`推奨、最も高速に完走する）を選び、
   uv導入・venv構築・モデル取得・実動作確認まで完走させる。
5. **記録**: 各ダウンロードの所要時間とサイズ（本機のuv package cacheが温cacheの場合は
   その旨を明記する）。

## 3. 2回目以降の起動（対話）

1. GUIを終了し、再度スタートメニューから起動する。
2. **確認**: ウィザードが表示されず、通常画面に直接遷移すること。

## 4. アンインストール — 対話確認chainの目視（対話）

自動化されたサイレントアンインストールの検証（AISTATE.md参照）は、確認ダイアログを一切
出さない経路だけを通っている。対話経路の`MsgBox`によるYes/No確認chain自体は、実際に
ボタンをクリックしないと動作を確認できない。

1. 「アプリと機能」から utteran をアンインストールする（`/VERYSILENT`を付けない）。
2. **確認**: 最初に「アプリ本体は常に削除される」旨の情報ダイアログが表示されること。
3. **確認**: 続けて、GUI設定／プロファイル実行環境／ダウンロード済みモデル／ジョブ履歴／
   ffmpegについて、それぞれYes/Noの確認ダイアログが順に表示されること。
4. **確認**: プロファイル実行環境・モデル・ジョブ履歴のダイアログには、対象のサイズが
   括弧内に表示されること。
5. 一部の項目だけ「はい」を選び、残りは「いいえ」を選ぶ。
6. **確認**: 「はい」を選んだ対象だけが実際に削除され、「いいえ」を選んだ対象は残ること。
7. **確認**: 完了後、残った対象の場所を示す情報ダイアログが表示されること。

## 5. SmartScreen警告の実機確認（対話・ネットワーク経由の入手が前提）

ローカルビルドしたexeをそのまま実行しても、Windows Defender SmartScreenの警告は
再現しない（Zone Identifier - ファイルの出所情報 - がローカルビルドには付与されないため）。
実際の警告を確認するには、GitHub Releasesとして公開したファイルを**別マシン、または
同一マシンでも一度ブラウザ経由でダウンロード**してから実行する必要がある。

1. GitHub Releasesからインストーラーをブラウザでダウンロードする。
2. ダウンロードしたファイルを実行する。
3. **確認**: 「Windows によって PC が保護されました」の警告が表示されること。
4. **確認**: 「詳細情報」→「実行」の手順でインストールを継続できること。
5. **確認**: README記載の回避手順と実際の画面文言が一致すること（Windowsのバージョンにより
   文言が変わる可能性があるため、乖離があれば README を更新する）。

## 6. アンインストール後の再インストール（対話）

1. 手順4で一部データ（`.venvs`等）を残したまま、再度インストーラーを実行する。
2. **確認**: 再インストール後、初回セットアップウィザードが表示されないこと
   （既存の`.venvs`と`settings.json`相当のデータが残っていれば`first_run=false`と
   判定されるはず）。
3. **確認**: 残っていたプロファイル環境がそのまま利用できること。

## 記録すべきこと

- 各手順の合否
- インストーラーのサイズ、インストール完了までの所要時間
- 初回起動からセットアップ完了までの所要時間、各ダウンロードのサイズ
- SmartScreen警告の実際の文言（バージョン差異の記録）
- 利用者体験上の気づき（README・ウィザード文言の過不足など）
- 実機で確認できなかった項目とその理由

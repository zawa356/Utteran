Utteran is an open-source application for transcribing meetings, interviews, talks, and other recordings.
It does not send your input audio to a cloud transcription API.

## Features

<CardGrid>
  <Card title="Local processing">
    Run Whisper-based recognition engines on your computer. An internet connection is needed to download models and dependencies initially.
  </Card>
  <Card title="Speaker diarization">
    Optionally group speech by speaker using a supported diarization model.
  </Card>
  <Card title="Flexible exports">
    Export SRT, VTT, JSON, TXT, and Markdown for subtitles, meeting notes, and further processing.
  </Card>
  <Card title="Desktop app and CLI">
    Use the Windows desktop interface for day-to-day work, or the CLI for automation and advanced workflows.
  </Card>
</CardGrid>

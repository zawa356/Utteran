Utteranは、会議・インタビュー・講演などの音声・動画を文字起こしするオープンソースソフトウェアです。
文字起こし処理のために入力音声をクラウドの文字起こしAPIへ送信しません。

## 主な機能

<CardGrid>
  <Card title="ローカルで処理">
    Whisper系エンジンを利用し、手元のPCで文字起こしします。モデルの初回取得などにはネットワーク接続が必要です。
  </Card>
  <Card title="話者分離">
    対応するモデルを利用して、発話を話者ごとに整理できます。話者分離はオプションです。
  </Card>
  <Card title="用途に合わせた出力">
    SRT、VTT、JSON、TXT、Markdownに出力。字幕制作や議事録の下書きに使えます。
  </Card>
  <Card title="GUIとCLI">
    WindowsデスクトップGUIで操作できます。自動化や高度な操作向けのCLIも用意しています。
  </Card>
</CardGrid>

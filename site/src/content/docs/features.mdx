## 文字起こし

- 音声・動画ファイルからテキストを生成
- faster-whisper、whisper.cpp、OpenVINO GenAIなど複数の実行経路
- 単一ファイルとフォルダー単位の一括処理
- 段階別の再開・再利用により重複処理を抑制

推論エンジンの利用可否と性能は、OS、デバイス、モデル、導入済み依存関係によって変わります。

## 話者分離

pyannote.audioを使用して、音声の発話区間を話者ラベルごとにまとめられます。オプション機能のため、無効にしたまま文字起こしすることも可能です。話者分離は実在する人物の名前を自動判定するものではありません。

## デスクトップGUI

Windows GUIから、入力選択、設定、進捗・中断、結果検索、履歴確認、出力形式の変更を行えます。

:::note[開発状況]
GUI/UXの全面刷新を進めています。このサイトでは開発中の画面や未リリース機能を、公開済み機能として案内しません。
:::

## 出力形式

| 形式 | 主な用途 |
| --- | --- |
| SRT / VTT | 動画字幕 |
| JSON | 後処理・外部ツールとの連携 |
| TXT | プレーンテキスト |
| Markdown | 議事録やメモの下書き |

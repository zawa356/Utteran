Utteranは文字起こし・話者分離をローカル環境で実行する設計です。**入力音声をクラウド文字起こしAPIに送信しません。**

ただし、「ローカル処理」と「一切通信しない」は同じ意味ではありません。

## 外部通信が必要な場面

- 初回セットアップでの依存ライブラリや音声認識モデルの取得
- 話者分離モデル利用条件への同意、Hugging Faceトークンの準備・確認
- GitHub Releasesや関連ドキュメントの参照

ダウンロード済みモデルの利用方法や依存関係によって、通信の必要性は異なります。完全オフライン運用を前提とする場合は、構成ごとの実機検証を行ってください。

## データの管理

UtteranのGUIでは、文字起こし結果やジョブ履歴などをローカルに管理します。ポータブル版は、アプリの管理データを展開先に保存する設計です。トークンや履歴の保持・削除条件は配布形式によって異なります。

セキュリティやデータ消去を含む詳細は[README](https://github.com/zawa356/Utteran/blob/main/README.md)と[公開リポジトリ](https://github.com/zawa356/Utteran)を確認してください。公開サイトで処理結果や音声ファイルを収集する機能は提供していません。

# utteran ポータブル版

`utteran-gui.exe` を起動してください。インストールは不要です。初回利用時には、選択した
プロファイルの仮想環境とモデルをインターネットから取得します。

生成される設定、ログ、ジョブ履歴、モデル、キャッシュ、ffmpeg、native build、`.venvs` は
すべて、このフォルダーの `data` 配下に置かれます。利用を終えるときは、必要な出力を別の場所へ
移したうえで展開フォルダー全体を削除してください。

## 制約

- Hugging Faceトークンは保存されません。GUIを起動するたびに入力してください。
- `.venvs` とモデルの取得後は数GBを使用します。
- 展開フォルダーを移動すると、絶対パスの変化によりプロファイルの再構築案内が出る場合があります。
- USBメモリ上では、環境構築、モデル読込、文字起こしが遅くなる可能性があります。
- インストーラー版と同じ `utteran-gui.exe` を使用するため、Smart App Controlの制限は回避しません。
